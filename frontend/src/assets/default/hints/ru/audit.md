# Журнал действий

Журнал фиксирует значимые изменения: входы, правки пользователей и прав, настройки, административные операции.

- Записи появляются в пределах TTL (до 30 секунд).
- Фильтры: пользователь, тип события, период.
- События RBAC — изменения ролей и индивидуальных прав.
- Удаление записей — только администратором.
